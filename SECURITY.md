# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory flow for `webvibecoding/streamboard-companion` and include the
affected version, reproduction steps, expected impact, and suggested remediation.

Avoid including real Streamboard device tokens, Google sessions, or streaming
platform OAuth credentials. We will coordinate disclosure after a fix is available.
